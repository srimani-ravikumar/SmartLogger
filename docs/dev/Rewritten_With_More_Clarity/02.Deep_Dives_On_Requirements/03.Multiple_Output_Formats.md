## Framework should support multiple output formats

* Plain Text, JSON, XML

## Framework should support formatting rules according to each output format

* Each output format should define its own formatting rules while maintaining a consistent log message structure.

## Framework should be extensible enough to support new output formats in the future

* New output formats should be added without modifying the existing framework implementation, following the Open/Closed Principle.
