## Framework should include all necessary information in every log message

Each log message should contain the following fields:

| Field             | Description                                              |
| ----------------- | -------------------------------------------------------- |
| **Timestamp**     | UTC timestamp when the log message was created           |
| **LogLevel**      | Severity level of the log message                        |
| **Message**       | Actual log message content                               |
| **Source**        | Name of the component or class generating the log        |
| **ThreadId**      | Managed thread ID that generated the log                 |
| **CorrelationId** | Unique identifier used to trace requests across services |

## Framework should format log messages based on the selected output format

```text
Plain Text → Layout → Tokens → String

JSON → Field Selection → Object → Serialize

```
