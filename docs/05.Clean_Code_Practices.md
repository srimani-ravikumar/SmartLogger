## File Naming Intuition

You need to split responsibilities:

1. File Naming → ALWAYS ACTIVE
2. Rolling → CONDITIONAL TRIGGER

Think like:

```
File Naming decides:
    "What should the file be called?"

Rolling decides:
    "When should we move to the next file?"
```
