```mermaid
---
title: SmartLogger (Interaction Flow)
---
sequenceDiagram
    participant App as Client
    participant Manager as LoggerManager
    participant Factory as LoggerFactory
    participant Logger as LoggerImplementation
    participant Filter as ILogFilter
    participant Appender as ILogAppender
    participant Formatter as ILogOutputFormatter
    participant Layout as ILogLayoutStrategy
    participant Token as ITokenRendererStrategy

    App->>Manager: LoggerManager.Initialize(configuration)
    App->>Manager: LoggerManager.GetLogger(name)
    Manager->>Factory: GetOrCreateLogger(name)
    Factory-->>Manager: Logger instance
    Manager-->>App: Logger

    App->>Logger: logger.Info(message)

    Logger->>Filter: Apply filters
    Filter-->>Logger: Pass / Reject

    alt Passed
        Logger->>Appender: Send log

        Appender->>Formatter: Format(message)

        alt PlainText
            Formatter->>Layout: Apply pattern
            Layout->>Token: Replace tokens
            Token-->>Layout: Rendered values
            Layout-->>Formatter: Formatted string
        else JSON/XML
            Formatter-->>Appender: Structured output
        end

        Formatter-->>Appender: Final output
        Appender-->>Logger: Written to destination
    else Rejected
        Logger-->>App: Discard log
    end
```
