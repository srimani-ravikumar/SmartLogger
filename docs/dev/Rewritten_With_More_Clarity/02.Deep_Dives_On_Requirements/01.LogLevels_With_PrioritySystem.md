## Framework should support multiple log levels

* Fatal, Error, Warning, Info, Debug, None

## Framework should be extensible enough to support new log levels in future


## Framework should support log level scoping

* Root level: Applied at the global scope (configured via configuration).
* Appender level: Applied at the appender scope (configured via configuration).
* Logger instance level: Applied at the individual logger instance level (configured via configuration, or overridden using the core APIs during implementation).

## Framework should resolve the minimum log level while retrieving a logger instance from LoggerManager

* Resolved log level = Minimum of logger instance level, appender level, and root level.

## Framework should not log messages below the resolved log level

* When the resolved log level is **Warning**, all **Debug** and **Info** log messages should be ignored.
